# 蒼井音呼 — 第2案「詩集をめくる」

ユーザー指定の `aoiinko_2` Gitフォルダーに制作した比較用の独立サイトです。元案の `aoineko` は変更していません。

## デザイン

名前と短い言葉を置いた詩集の表紙から始まります。スクロールすると薄い紙が前のページに重なり、見出し、文章、挿絵の順に静かに現れます。本文は18px（スマートフォン16px）、長いページは最後まで読んでから次の紙面に移ります。青いインコと白い柴犬は余白や章末の小さな挿絵です。本文を横切る動物や画面の白転はありません。

原稿は現行サイトの短縮版を使用。経歴は5項目の開閉式。お問い合わせ先、掲載誌写真、俳句原文は後日追加する設定です。未提供の情報は作成していません。

## プレビューと編集

このフォルダーで `node serve.mjs` を実行し、http://127.0.0.1:4174/ を開きます。元案の4173とは別に確認できます。追加パッケージは不要です。`index.html` 単体でも本文と操作を利用できるよう、設定・動作をインラインにも同期しています。

- `index.html`: 全5セクション、SEO、共有情報
- `styles.css`: 紙面、挿絵、レスポンシブ、ページの重なり
- `script.js`: ページ送り、目次、表示演出、お問い合わせ、掲載作品
- `site-config.js`: 連絡先と掲載作品
- `assets/`: この案で使用する素材。元案から必要なファイルだけ複製

`script.js` または `site-config.js` の変更後は `node sync-site.mjs` を実行してください。お問い合わせ先は `contactUrl` にHTTPSのフォームURLまたは `mailto:メールアドレス` を設定します。

掲載誌を追加する場合は `publications` に `image`, `alt`, `title`, 任意の `caption`, `haiku`, `vertical` を設定します。俳句は `vertical: true` で縦書きになります。

## 動きと読みやすさ

動くのは紙面のごく小さな傾きと重なり、見出し・段落・挿絵のフェードです。ページの内容が画面より長い場合は、最後まで自然にスクロールしてから紙面が留まります。目次やページ末のリンクで各章へ直接移動できます。経歴は標準のdetails要素を使い、JavaScript無効時にも開閉できます。

「動きを止める」で演出を省略し、同じタブ内で設定を保存します。OSのモーション抑制時も静止表示です。キーボード操作・フォーカス表示・44px以上の操作領域に対応しています。

## 公開前設定

この案はローカル制作済み・未公開です。既存Git remoteに対応する公開候補URL `https://michiocorporation.github.io/aoiinko_2/` をcanonical / OGP / Twitter Cardに設定しています。公開先を変える場合はURLを揃えて更新してください。

比較段階のためHTMLに `noindex, nofollow`、robots.txtに `Disallow: /` を設定しています。公式サイトとして採用し検索掲載する際は変更します。これらは閲覧制限やパスワード保護ではありません。
